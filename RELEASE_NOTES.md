### Option 2: Detailed

```
# Upstack v1.0.0 - Initial Release

Export your Obsidian notes to Substack-compatible HTML with one click! Upstack automatically converts Markdown to clean, semantic HTML optimized for Substack's editor.

## What's Included

### Core Features
- **One-Click Export**: Copy your note as Substack-ready HTML instantly
- **Automatic Image Embedding**: Local images converted to base64 data URIs
- **Mermaid Chart Support**: Diagrams automatically converted to PNG images
- **Full Markdown Support**: Callouts, footnotes, tables, code blocks, task lists, and more

### Supported Features
- Obsidian-style images (`![[image.png|caption]]`)
- Mermaid charts (flowcharts, sequence diagrams, etc.)
- Callouts/Admonitions (note, tip, warning, error, etc.)
- Highlights (`==text==`)
- Footnotes with clickable references
- Tables (converted to text format)
- Code blocks and inline code
- Task lists with checkboxes
- Wikilinks conversion
- All standard Markdown formatting

## Installation

1. Download `main.js` and `manifest.json` from this release
2. Create folder: `.obsidian/plugins/upstack/` in your vault
3. Copy both files into that folder
4. Reload Obsidian
5. Enable the plugin in Settings → Community Plugins

## Usage

1. Open any Markdown note in Obsidian
2. Click the Upstack icon (stylized "U") in the ribbon, OR
3. Use command palette: "Copy current note as Substack-compatible HTML"
4. Paste directly into Substack's editor

## Documentation

Full documentation available in the [README](https://github.com/memmmmike/upstack/blob/main/README.md).

## Requirements

- Obsidian 0.15.0 or higher
- Works on desktop and mobile
```
